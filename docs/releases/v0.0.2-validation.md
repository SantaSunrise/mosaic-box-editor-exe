## 映像境界

ChromiumのローカルHTTP再生で、合成動画（720p・30fps・2秒）と実動画（1080p・24fps・約15.6秒）を各3周比較した。
新方式は待機プレイヤーの先頭（0〜約0.8ms）に交代し、最後のフレームから交代までの時間は合成動画で約34〜36ms、実動画で約53〜54msだった。実動画には約11msの音声末尾がある。

従来方式の最終フレームから次のフレーム表示時刻までの間隔は、それぞれ約33〜67ms、約49〜72msだった。ただし新方式は交代イベント時刻、従来方式はフレーム表示予定時刻を測定しており、同じ指標ではない。厳密な短縮率や実機WebView2での無瞬断を示す数値ではない。

## 音声の制約

440Hz・48kHz AAC付き2秒動画をWeb Audioで記録し、3ms以上の無音を比較した。従来方式は約8〜11ms、新方式は約31〜48msだった。映像の先読みは音声のギャップレス再生を実現するものではなく、この条件では音声の無音区間が長くなる。音声境界の厳密な確認には別の再生手段が必要。
