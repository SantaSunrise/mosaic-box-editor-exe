「局部モザイク確認」（AIによる判定）を追加し、動画ライブラリの見た目と判定の速度を大きく改善しました。

### 変更点

- **局部モザイク確認を追加**: ヘッダーのボタンから、開いているフォルダの動画・画像にモザイクの漏れがないかをAIで確認します。
  - Cloudflare Accessでログインして使います。現状ログインできるのは、許可されたメールアドレスのみです。
  - 動画は等間隔の10フレーム、画像は1枚を判定します。確率80%以上でNG、50〜80%は要確認です。
  - 保存済みの範囲の外にある検出は「未モザイク疑い」として表示します。
  - 結果の行から編集画面の該当フレームへ移動し、検出枠を重ねて確認できます。
  - 検出枠をすべて包む矩形を「モザイク候補」（要確認の動画は「モザイク候補（要確認）」）として水色の破線で表示します。「候補を範囲に追加」を押したときだけ範囲に追加され、範囲は自動では変わりません。
- **動画ライブラリを刷新**:
  - 各行の左に動画のサムネイルを表示します（表示された行から順に作成します）。
  - 「AI NG」「AI要確認」「AI OK」の絞り込みと件数を追加しました。
  - 「動画ライブラリ」の見出しと注釈を削除し、フォルダのパスをヘッダーのロゴの右に表示します（長いときは中間を省略し、全体はホバーで確認できます）。
  - 行とサムネイルを大きくし、絞り込みボタンを小さなチップにして一覧を広げました。
- **判定を高速化**: Workerへの同時リクエストを全体で最大20に絞って並列で送ります。混雑時（429・529）や接続エラーは最大3回再送します。

### ダウンロード

`Mosaic-Box-Editor-v0.1.0-windows-x64.zip` を**フォルダ全体で展開**し、`mosaic-box-editor.exe` を起動してください。
ffmpeg・ffprobeは同梱済みです。Windows 10 / 11（x64）、WebView2 Runtimeが必要です。
既存の動画フォルダと `boxes` の保存データを引き続き利用できます。

### ご利用上の注意

- 局部モザイク確認はAIによる補助です。見逃しや誤判定が起こり得るため、最終的な確認は目視で行ってください。
- 判定に使うフレーム（画像）は、Cloudflare経由でTypeSafe（Jev）に送信されます。送信してよい素材かを確認してから使ってください。
- 「モザイク候補」は表示のみで、範囲は自動では変わりません。
- 局部モザイク確認にはネットワーク接続とCloudflare Accessへのログインが必要です。それ以外の編集・書き出し機能は、これまでどおり使えます。
