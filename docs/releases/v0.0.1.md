Windows向けの最初のポータブルリリースです。

### 使い始める

`Mosaic-Box-Editor-v0.0.1-windows-x64.zip` をダウンロードし、**全体を展開して** `mosaic-box-editor.exe` を開いてください。
ffmpeg・ffprobeは同梱済みです。移動するときも `bin`・`licenses` を含むフォルダ全体を移動してください。
Windows 10 / 11（x64）、WebView2 Runtimeが必要です。署名なしのポータブル版です。

### 主な機能

- 動画フォルダの一覧表示と、設定状態が分かるバッジ。
- 矩形・投げ縄・ブラシによるモザイク範囲の編集、自動保存、範囲の引き継ぎ。
- 範囲／モザイクのプレビュー、5段階の再生速度、ホイールでの拡大縮小。
- 範囲表示の5色・3段階の濃さ、ブラシサイズの中央プレビュー。
- 個別書き出しと、範囲保存済み・未出力の動画の一括書き出し。
- ターミナルを表示しないGUI起動とFFmpeg実行。

### 制限

選択範囲は全フレームに共通です。自動追跡はありません。
プレビューのコーデック対応はWebView2に依存します。一括書き出しの中止は現在の1本が終わってから反映されます。
