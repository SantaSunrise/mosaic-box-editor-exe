# 費用と無料枠の見積もり

## 現在の構成（typesafe-api）の費用

Jev を TypeSafe の API 直接で呼ぶ構成では、費用は TypeSafe 側の従量課金（入力 **$0.042 / 100万トークン**、出力 $0）です。
Cloudflare の Workers AI の無料枠（下記）は使いません。

実測（2026-10-23、`worker/src` のコードで実 API を呼んだ。`noul` + `box` の 2 問、1 フレームごと）:

| フレーム                        | 入力トークン  |
| ------------------------------- | ------------- |
| 1024×576 の JPEG（s13 の 2 枚） | 約 1,921 / 枚 |
| 1024×768 の JPEG                | 2,439         |

- 1024×576 で **1 フレーム約 $0.00008**、動画 1 本（10 フレーム）で約 19,200 トークン = **約 $0.0008**。
  1,000 本で約 $0.8（1 日 100 本でも約 $0.08）。縦横比によって画像のトークン数が変わるため、目安です。
- 解像度を下げれば減ります（`MAX_EDGE`）。別の見積もり（約 $0.0006 / 本）は 768px 前後の場合の概算です。
- Workers の実行自体は Workers Free で収まる想定です（未計測）。

以下は、将来 workers-ai バックエンドに切り替えた場合の Workers AI 無料枠の見積もりです。

調査日: 2026-10-22。数値は公式ドキュメントの記載に基づく試算で、実測ではありません。

## 前提（公式ドキュメント）

| 項目                          | 値                                                 | 出典                                                                                                                                |
| ----------------------------- | -------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Workers AI の無料枠           | **10,000 Neurons / 日**（Free・Paid 両プラン）     | [Workers AI pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/)                                                |
| 超過分の単価                  | $0.011 / 1,000 Neurons                             | 同上                                                                                                                                |
| トークン価格と Neurons の関係 | 「Price in Tokens 列は Price in Neurons 列と等価」 | 同上                                                                                                                                |
| Jev の価格                    | 入力 **$0.042 / 100万トークン**、出力 $0           | [typesafe/jev モデルページ](https://developers.cloudflare.com/ai/models/typesafe/jev/)                                              |
| 画像1枚あたりのトークン数     | **公式記載なし**                                   | 参考: 画像1枚 + 質問2問の例で `input_tokens: 756`（[LiteLLM ドキュメント](https://docs.litellm.ai/docs/decisions/typesafe_images)） |

> **無料枠が Jev に適用されるかは未確認です。** 料金ページに Jev の行はなく、第三者（third-party）モデルに
> 無料枠が使えるかの記載もありません。一部の第三者モデルは「有料の支払い方法が必要」と明記されています
> （moonshotai / zai-org / deepseek-ai。typesafe は記載なし）。デプロイ後にダッシュボードの Workers AI 使用量で
> Neurons の計上を確認します（[未決事項](open-issues.md) #3）。

## 計算

1. Jev の価格を Neurons に換算: $0.042 ÷ $0.011 × 1,000 = **約 3,818 Neurons / 100万入力トークン**
2. 無料枠をトークンに換算: 10,000 ÷ 3,818 × 100万 = **約 2,619,000 入力トークン / 日**
   （金額では 10,000 Neurons = $0.11 / 日相当）
3. 1 枚あたりのトークン数 T で割る。動画は 1 本 = 10 フレーム。

本アプリの 1 リクエスト = 長辺 1024px 以下の JPEG 1 枚 + 質問 2 問（`noul` と `box`）。
画像のトークン化規則が非公開のため、3 通りで試算します。

| 1 枚あたり入力トークン T      | 画像（枚 / 日） | 動画（本 / 日、10 フレーム） |
| ----------------------------- | --------------- | ---------------------------- |
| 756（公開例と同等）           | **約 3,460**    | **約 346**                   |
| 1,500（中間）                 | 約 1,740        | 約 174                       |
| 3,000（高解像度で増える場合） | 約 870          | 約 87                        |

計算式: 枚数 = 2,619,047 ÷ T（小数点以下切り捨て、表は概数）。

## 無料枠を超えた場合・無料枠が使えない場合の費用

T = 1,500 として、1 枚 = 1,500 × $0.042 / 100万 = **$0.000063**。
動画 1,000 本（10,000 フレーム）でも 1,500万トークン = **約 $0.63** です。

## 実測で見積もりを更新する方法

- 判定ダイアログの集計欄に「判定フレーム数」と「入力トークン合計」を表示しています
  （Worker が Jev の `usage.input_tokens` を合計して返す）。入力トークン合計 × $0.042 / 100万 が TypeSafe API の費用の目安です。
- 代表的な素材で 20〜50 フレーム判定し、`入力トークン合計 ÷ フレーム数` を T として上の式に入れてください。
- 同時に Cloudflare ダッシュボードの Workers AI 使用量（Neurons）を確認し、
  手順 1 の換算（約 3,818 Neurons / 100万トークン）と一致するかを確かめます。
